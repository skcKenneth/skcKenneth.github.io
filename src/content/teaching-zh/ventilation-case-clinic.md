本案例把公開課室通風研究轉化為一組建模與評議任務。學生無需進入私人程式庫；公開文章、方程、核准圖像與已報告結果表足以完成結構化分析。

## 驅動問題

三間課室共用有限室外氣流容量。時間表預測佔用，但一班學生可能未通知便轉房，總風機容量也可能日間下降。應如何分配氣流？又應用哪個指標定義好決策？

## 數學概念

- 離散時間質量平衡；
- 單位與濃度變化；
- 共用不等式約束；
- 反應式與預測式控制；
- 人員加權及最壞情況指標；
- 配對實驗比較；
- 敏感度與遞減回報。

## 教學序列

### 1. 先讀系統，後讀結果

學生查看[公開研究筆記](/zh/writing/when-the-timetable-lies/)的共用氣流圖，辨認狀態變數、控制變數、擾動、約束與輸出，再在不引用已報告結論下寫出系統邊界。

### 2. 檢查一個質量平衡步驟

使用提供的房間體積、室外濃度、佔用與氣流指令，計算下一步濃度變化方向及約略大小，讓程式輸出重新連接到單位與守恆。

### 3. 比較控制器資訊

| 控制器 | 使用時間表？ | 使用 CO₂ 量測？ | 前瞻？ | 直接處理錯誤時間表？ |
|---|---:|---:|---:|---:|
| 固定時間表 | 是 | 否 | 否 | 否 |
| 反應式 CO₂ | 否 | 是 | 否 | 濃度上升後 |
| 時間表 MPC | 是 | 是 | 是 | 間接 |
| 緩衝 MPC | 是 | 是 | 是 | 透過固定餘量 |

學生預測哪個控制器使用更多風機指令，以及哪個對未通報轉房反應最快。

### 4. 解讀兩個衝突指標

在合成基準中，預測控制器降低人員加權暴露，但不加權全日峰值較高。學生解釋共用容量目標如何改善一個指標，同時惡化另一個。

### 5. 挑戰 1000 ppm 線

學生把句子分成有支持、沒有支持或需要更多證據，尤其要分辨一致實驗目標與普遍健康或安全閾值。

### 6. 設計下一個實驗

小組各提出一項現場校準及獨立評估。好答案需交代量度甚麼、估計哪些參數、哪些資料必須留出，以及預先聲明哪個成功指標。

## 證據產物

1. 系統邊界圖；
2. 一個已檢查質量平衡計算；
3. 控制器資訊表；
4. 一段雙指標解讀；
5. 聲稱分類表；
6. 一頁下一實驗協議。

## 評核重點

案例重視單位一致、對控制資訊的因果推理、辨認指標衝突及有紀律的聲稱界線；不獎勵把已報告控制器當成完整樓宇方案。

## 延伸

進階小組可用不確定性分布取代固定五人緩衝，建立機會約束。延伸必須說清楚控制哪個概率，以及如何用獨立佔用紀錄校準。
