# 初一全冊探究：課程對照與教師檢視

學生入口：[/math-studio/](https://skckenneth.github.io/math-studio/)，選「查看12章探究地圖」。每章側欄亦有「本章探究」。

本版為原有 `number`、`balance`、`tariffs` 深化，新增九項，共21項探究。初一12項按教材章序排列；三角形、乘法面積與平均數是跨年級延伸。初二及高一原活動保留。全部材料為本網站原創教學敘述，沒有複製教材或解答手冊。

## 課程對照

| 章節 | 活動 ID | 核心成果 | 反例或邊界 | 延伸研究 |
|---|---|---|---|---|
| 有理數 | number | 比較三人距離的總和及最大值 | 總路程最小不一定令最遠者路程最小 | 移動中間住宅，追蹤兩種最優位置 |
| 有理數的運算 | powers | 按指數奇偶及零分類 | 奇次方兩式相同；零須另列 | 自製相同結果的不同結構並分類 |
| 代數式 | matches | 把三個公式連到同一幅共邊圖 | 空圖及分開排列不適用3n+1 | 分成兩列，推出3n+2 |
| 整式的加減 | magic | 以係數消去解釋固定答案 | a≠c 時仍依賴起始數 | 設計兩套固定為12的魔術 |
| 一元一次方程 | balance | 比較操作前後完整解集 | 乘零增加解；除零未定義；原式恆等 | 研究「乘零一定不等價」的例外 |
| 幾何圖形初步 | angles | 分清開口、顯示長度及旋轉 | 長邊不一定形成大角 | 製作外觀不同的等角圖 |
| 相交線與平行線 | parallels | 每步論證列明所需條件 | 非平行時同位角不相等；對頂角仍相等 | 由同旁內角互補反推平行 |
| 實數 | roots | 用精確平方比較保持上下界 | 完全平方數、零與近似等號 | 比較√3、√5、√9的界 |
| 平面直角坐標系 | routes | 分開終點、平移量及總路程 | 加來回指令不改終點但增加路程 | 系統列出到(2,2)的六條最短路線 |
| 二元一次方程組 | tickets | 檢查解是否為非負整數 | 分數張數、超額收入、同價資訊不足 | 增加一項獨立資料以唯一還原 |
| 不等式與不等式組 | tariffs | 價格比較與限制取交集 | 較便宜仍超預算；沒有整數同價點 | 改預算，分類兩方案可行性 |
| 數據收集、整理與描述 | sampling | 區分選樣偏差與重抽波動 | 問完整個偏向小組仍不能代表全校 | 比較10／40人的30次重抽及圖表刻度 |

## 課堂與自學

核心約25–35分鐘：問題與預測5分鐘、實驗10分鐘、比較與解釋10分鐘、遷移5分鐘；延伸另約10–20分鐘。按學生需要分成兩課。每項至少三組指定案例、三層提示、三個依目前數值回應的追問、獨立遷移及參考論證。

2至4人小組先各自寫預測，再輪換操作、記錄、提問。自學者使用明確標示的假想觀點。只核對小步驟數值，不用字數或關鍵字判斷研究品質，亦不影響章節練習分數。

比較前先保存證據，再選兩筆並排；目前圖表與追問會跟參數更新，已保存的證據維持原值。切換案例、提示、活動及重新整理會保留草稿。沒有跨裝置同步或即時多人共編。

### 同事檢視清單

- 學生能否用第一個小例子起步？如不能，卡在哪個先備概念？
- 從實際數值到符號的哪一步仍有跳步？記錄學生原話。
- 指定案例是否讓學生看見「只改一個條件」？
- 學生會否把幾次成功當作證明？哪個追問能促使補條件？
- 提示展開後仍有思考空間，還是只需抄答案？
- 學生能否指出第幾筆證據支持哪個主張？
- 原先猜想如何修訂？有沒有保留反例而非刪掉？
- 遷移題能否獨立完成？按三項準則記錄未呈現／部分／完整證據。
- 請檢查手機、鍵盤、下載與列印，並以「活動、步驟、參數、問題」回報。

教師備課面板另有各課先備、三問、預期策略、迷思及離堂題。下載紀錄包含教師觀察與下次調整，方便共同備課；學習成效仍須由課堂實證檢視。

## 資料與維護

`inquiry-g7-core.js` 定義參數範圍及純數學計算；`inquiry-g7-content.js` 定義原創任務；`inquiry-g7-ui.js` 沿用既有 Inquiry 介面接上圖表、記錄及年級導覽，樣式在 `inquiry-g7.css`。所有圖表及證據來自相同計算結果；未使用AI服務或新增外部依賴。

內容版本 `g7-1`；本機鍵 `math-studio-inquiry-g7-v1`。讀取既有 `math-studio-inquiry-v2` 時將舊證據標為 `legacy-v2`，保留原字串，亦不覆寫舊鍵。新證據帶版本與參數。每課最多12筆證據，可選兩筆比較；核對保留最近20次，路線最多120步。儲存被拒時仍可在本次工作階段操作並下載UTF-8文字。學習單列印包含學生原文及已展開的提示；未展開的答案維持隱藏。需要教師版時，先展開教師備課與所需參考。

抽樣總體完全合成：200人，100人選A。特定小組40人，其中36人選A；其餘160人中64人選A。種子控制Fisher–Yates無放回抽樣，30次重抽使用起始種子加0至29。修改縱軸不改資料；不得把結果當作真實校園證據或保證更大樣本單次必然更準。

精確處理：平方根小數界以整數縮放平方比較；收費用十分之一元比較端點；售票以非負整數枚舉交叉檢查實數解；方程除法以分數展示係數。

## 驗收指令

`pnpm test:math-studio` 包含原題庫／互動回歸、六章學習支援及初一探究測試。新增測試覆蓋12課指定案例、獨立數學核對、種子重現、舊紀錄相容、拒絕儲存、草稿與比較保存。另執行 `pnpm run check:security` 及 `pnpm build`，再於實際瀏覽器檢查桌面／390px手機、鍵盤、刷新、追問、下載及其他年級。

部署沿用既有Pages工作流程，確認合併提交的Actions成功、公開資產SHA-256一致及公開互動後才報告已上線。部署證據不當作學生學習成效證據。

設計參考：[NRICH：Low Threshold High Ceiling Tasks](https://nrich.maths.org/articles/low-threshold-high-ceiling-tasks-secondary-classrooms)、[EEF：Developing problem solving strategies](https://educationendowmentfoundation.org.uk/news/eef-blog-developing-problem-solving-strategies-in-mathematics)。具體任務、流程與時間均為本網站設計，非文獻規定的唯一做法。
