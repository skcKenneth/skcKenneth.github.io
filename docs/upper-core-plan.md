每個核心包對照一組原書課時，供鞏固或章末整理使用。原書七上 50 課時、八上 52 課時；本輪不把每組內容壓縮為一節新授課。首次教授技能仍按教材分節處理。

## 兩條路線

普通班 40 分鐘：先備 4、短探究 5、示範與帶做 8、獨立練習 15、訂正 5、離堂 3。進階班 40 分鐘：探究 18、整理 4、精選練習 13、離堂 5。每包仍為示範一題、帶做一題、先備兩題、獨立四題、離堂兩題、補練四題、進階兩題。

幾何題逐步減少證明支架，核對已知、對應、判定及結論；接受其他正確方法。分式題須保留原分母及除式的限制，不能因約分而刪除禁值；分式方程驗算原方程。科學記數法容許負數，係數須滿足 `1 ≤ |a| < 10`。

學生核心工作紙預設兩頁 A4，示範與帶做亦保留空白；補練另頁。學生、教師、投影均由同一題庫產生。揭示狀態只留在本分頁；重新載入及列印後回復學生版。紙筆作答不自動建立成績或瀏覽器學習紀錄。

## 來源與驗收界線

來源為教師提供的《大湾区初中数学三维课堂》七、八年級上冊正文、基礎訓練及答案冊。本輪直接核對目錄、課時及正文頁碼；正文 PDF 頁碼為印刷頁碼加三，基訓 PDF 頁碼為課時加二。每道新題記錄其對照課時。公開材料為按相同技能編寫的原創題，不重刊教材 PDF、原題或答案冊；新題答案另外以獨立數學核驗器及人工條件檢查核對，不聲稱逐題核對全套原書答案。

程式驗收見 `docs/upper-core-qa.md`。教師試教另記核心完成數、兩道離堂題及最常見兩項錯法；若不少學生未完成，先補支架或拆細步驟，再增加題量。學習成效尚待實際試教，不能由軟件測試推定。
