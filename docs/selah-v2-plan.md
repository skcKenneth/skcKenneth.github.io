# Selah 改版計劃

第一個里程碑係一堂可以打斷、追問、再接住聽嘅澳門競賽數學示範課。第二個里程碑係學生揀另一題，甚至貼自己條題目，都可以用同一套白板學。以下係建議設計同驗收條件。

## 從現況出發

Sitor 公開示範嘅流程包括從主題或教材開課、語音同步板書、中途舉手、框選局部快問、概念檢查同課後重溫。比較依據係官方公開頁所展示嘅操作。[Sitor 官方示範](https://sitor.cc/)

Selah 現行示範係一條題目、四個步驟、兩條選擇題。「找出不變量」有可以拖動嘅四分一圓圖。答疑會收到當前步驟同問題，未包含滑桿數值、學生所指嘅算式或上一輪問答。進度亦將自行答啱同按「查看解釋」記作同一種完成。[Selah 現行繁中課堂](https://skckenneth.github.io/zh/teaching/selah/)

## 第一階段 · 一堂可以打斷嘅課

以現有 2023/24 澳門校際數學比賽高中組第 5 題做完整樣板。

1. **入場。** 首屏顯示題目、一幅白板同「開始上堂」。按下後播放粵語講解配繁中字幕，英文版用英語。學生亦可以靜音睇字幕、重播一句或直接讀完整題解。桌面以白板為主，手機直向亦要同時見到老師指緊嘅位置同「舉手」掣。
2. **跟講。** 旁白叫學生拖動點，白板先畫兩軸同圓弧，再畫出穿過動點嘅直線。講到等號條件先標出對角線。將聲音、字幕、畫圖動作同停低等學生作答嘅位置，編成同一份有時間點嘅講稿。
3. **舉手。** 學生點選直線或算式，可以打字問「點解呢度最大？」。白板暫停並記低播放位置、所選物件、當時嘅 x 同已經講過嘅內容。導師喺同一幅圖標示對應位置，學生可再問「咁點解答案唔係 6？」。答完撳「繼續」，由打斷嗰句接返。第一版用點選已知物件，稍後先支援自由框選同語音輸入。
4. **驗收。** 在手機及桌面，用繁中及英文各走一次以上流程。將 x 拉到 4.5，回答應指出兩個根式相等；再將 x 改到 3，回答應指出其中一項係零。核對第二輪追問有分清和嘅上界 √6 同平方嘅上界 6。網絡逾時後，仍可由相同位置繼續講解。

沿用 Astro、GitHub Pages 同 Cloudflare Worker。核心講稿、圖形動作同兩套旁白以課堂資產預先準備；播放、暫停、重播由瀏覽器處理。Worker 處理自由提問，接收當堂有限嘅上下文，按教材可用嘅圖形及算式回傳要高亮嘅物件。數值、等號條件同示範答案用既有數學函式及已核對嘅題解驗證。試用時記錄每堂 AI 請求數、等候時間同失敗次數，再決定有冇需要轉模型。

## 第二階段 · 由答題去到識得自己做

- 用具體錯答決定點再教。例如學生以為 u + v 固定，就並排顯示 x = 3 同 x = 4.5 嘅兩組數值，再請佢比較 u² + v²。
- 做完示範，改問 √(x − 2) + √(10 − x) 幾時最大。驗收答案係 x = 6、最大值 4，學生亦要指出點解兩項相等就取得上界。分開記錄睇過解釋、用過提示、獨立完成變式題。
- 課尾生成一張可重開嘅溫習卡，包含當堂關鍵板書、學生卡住嘅一步同一條待重做嘅題目。先儲喺學生自己嘅瀏覽器。再加入一條幾何題同一條代數題，驗證同一個播放器支援唔同教法。
- 驗收包括答錯後走補講路線、揭答案後仍有獨立練習，以及重新開課時能回到需要重溫嘅一步。

## 第三階段 · 學生帶自己嘅題目入課

1. 首頁增加「揀一堂課」同「貼上我的題目」。先用已核對嘅澳門競賽題庫比對題意，命中就打開對應白板，並顯示年份、題號同原卷出處。
2. 題庫以外嘅題目先限定在支援嘅數學題型，根據題目生成教學草稿，核對定義域、推導、答案同圖形後先開始播放。遇到缺少附圖或條件唔齊，指出欠邊一項，等學生補充。
3. 之後開放相片及單頁 PDF。學生先核對辨識出嚟嘅根號、指數、分母及附圖，再確認開課。下一輪先評估多頁講義、多課路線、自由框選同到期重溫提示。
4. 用已收錄題、未收錄但條件完整嘅題，同缺圖嘅題分別驗收。學生應能分辨系統開啟咗已核對課堂、生成咗新課，定係仲需要佢補資料。

## 第一次試堂點決定下一步

邀請 3–5 位學生各自完成 Q5，觀察佢哋能否自行開課、指住正確物件發問、接續原來講解，同埋獨立完成變式題。若學生搵唔到舉手或回答對錯位置，先改呢段互動，再擴大題庫。呢啲係試堂要收集嘅結果。

## 講稿同音檔

Q5 講稿喺 `src/data/selah-classroom.mjs`。另外兩堂競賽課同根式變式課用 `src/data/selah-intake.mjs`。每段各有一份粵語、一份英語 MP3，喺 `public/audio/selah/` 按語言及段落命名。講稿改動時要一併更新對應音檔。產生新區間時，通用旁白帶學生睇白板標記，白板列出該題實際數值。

粵語用 ToJyutping 按語境標音，再用 Cantonese VITS 合成；英語用 Piper 的 Lessac Medium 模型。播放只需網誌上已製好嘅音檔。[Cantonese VITS](https://huggingface.co/xiaomaiiwn/vits-cantonese) · [ToJyutping](https://github.com/CanCLID/ToJyutping) · [Piper Lessac](https://huggingface.co/rhasspy/piper-voices/tree/main/en/en_US/lessac/medium)
