# 第一批：編輯視覺與讀前指南

執行基準：已發布並驗證的統整版 `8858cb9`。歷史規劃基準 `6a54eda` 保留於方案記錄。

## 改動

- 首頁維持五段，縮短介紹，使用曲線／節點插畫；最新三篇按日期更新，以一張重點圖文卡配兩張文字卡呈現。
- 首頁入門選讀排除已出現在最新文章的項目。現有模型可信度捷徑先通往風險與決策主題；第二批專題完成後再接入正式路線。
- 文章清單保留原篩選資料與文字卡；重點／精簡兩款卡共用完整標題、摘要、日期、閱讀時間及主題連結。
- 八個穩定主題各有一款裝飾 SVG。六篇試點另有編輯封面與中英文實際標題分享 PNG，正文科學圖件與 frontmatter 保留。
- 六篇雙語讀前指南按共同文章 ID 管理；手機常駐核心問題，其他資訊可用原生展開控制閱讀。非試點文章繼續使用原摘要。
- 分享 metadata 與 JSON-LD 使用已登記的文章分享圖；其他頁面沿用共用品牌分享圖。
