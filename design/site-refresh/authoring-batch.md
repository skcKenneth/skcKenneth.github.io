## 實作範圍

- 三篇中英文短札記沿用現有文章、分類、相關文章、RSS、收藏及閱讀工具；首頁最新三篇按實際日期更新，無圖卡片使用既有品牌圖案。
- 關於頁加入寫作緣起與選題方式，更新日期為本次實際編輯日期；既有經歷、作者次序與活動狀態保留。
- 初中抽樣與建模混合槽兩個課堂包，附課前準備、45／50 分鐘次序、學生工作紙、離堂題與獨立公開教師參考；教學總覽直接進入學生頁，再到教師參考。
- 課堂設定只接受已列明情境及有效整數種子。分享入口不讀寫學生回答或原工具紀錄；設定須在原活動手動套用。繁中限定的抽樣工具、建模 Python 下載及預先生成參照均清楚標示。
- 搜尋預設找到課堂入口；教師參考屬教學單元，需要選擇該類型或擴闊搜尋範圍。
- `pnpm review:content` 提供本機同步覆核佇列，按共同內容 ID、語言、依賴及指紋追溯。初始快照不等於完成覆核；只有明確記錄、具實際結論及版本的收據才算已覆核。
- `check:publish` 阻擋無效依賴／收據；尚待核對事項保留報告，不憑日期推定活動完成，也不改歷史發布日期。

## 驗證與發布

來源審閱與版本收據：753 個觀察項中，63 項在記錄的有限範圍內一致，兩項里程碑後續事實待確認，688 項舊內容仍為資訊性的未覆核狀態。收據涵蓋前兩批實際完成的編輯來源核對、本批札記／課堂包雙語核對，以及當前公開教材 metadata／版本／資產雜湊檢查；不是人工批准或獨立研究重現。詳見 `content-review/report.md` 及完整 JSON。

獨立只讀審閱修正了抽樣工具的年級／探索操作次序；教師平衡式及穩態答案分開呈現。課堂時間、Euler 手算、穩態值、原工具來源、既有紀錄格式與設定連結一致。教材 gate 實際核對 214 份競賽題解、27 個雙語講義單元及 94 份講義資產；既有工坊九項回歸通過。

本次構建使用已提交公開資產。四份生成 JSON 的 `source` 明確改為公開快照來源；逐份解析比較證明其餘欄位與原提交完全一致，資產內容、版本、雜湊、授權及來源白名單未變。佇列先正確指出兩個 manifest 及四個教材入口的來源標示變動，完成此具體核對後才追加六個收據，保留前次收據供追溯。

最終本機完整建置成功：4,431 頁、Pagefind 兩種語言 4,343 個索引頁；Astro 檢查零錯誤、零警告。43 組測試輸出合計 433 次通過、零失敗；此數字是各組報告的執行次數，並非 433 個不重複測試。原有高中題庫、數學排版、收藏及研習室儲存回歸一併通過。

實際瀏覽器檢查九類頁面、兩種語言、四個寬度及 100／200% 根字級，共 144 組，修正關於頁 grid 及英文長字換行後沒有頁面橫向溢出。200% 為本機文字設定，未宣稱瀏覽器 zoom 或完整 WCAG 認證。自選 `club-40`／`2048` 可更新網址、切換語言及返回；複製連結實際顯示成功。逾時／拒絕／手動選取後備另有雙語模擬回歸。投影模式在 360 px／200% 文字可用鍵盤開關、Escape 返回原焦點。搜尋「抽樣」預設一個學生入口；擴闊教學單元後有兩個結果，包括教師參考。
