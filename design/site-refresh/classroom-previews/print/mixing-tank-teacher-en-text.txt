50 minutes · Introductory modeling · pairs
Before you begin
Derivatives, units, Python functions and arrays. This is a 50-minute introduction to the existing
approximately 150-minute workshop, not its completion.
The well-mixed tank is an invented teaching system. No measured equipment, mixing
validation or plant-safety result is supplied.
Check Python loading before class and keep the reference CSV/notebook available. Allow
more time or use a teacher projection if Python functions and arrays are unfamiliar.
Ask learners to export an existing workshop draft before manually changing it. This pack does
not create a second draft or mark any of the workshop’s eight stages complete.
One-class sequence
5 min 01. Predict the long-run level
Sketch a 20 L tank: 2 L/min enters at 10 g/L; equal outflow, reaction 0.05/min, initial
concentration 0. Will concentration reach 10 g/L?
Teacher reasoning / look for
The prediction is about an invented system with a positive removal reaction. Keep it
before showing the reference curve.

Equal flows keep volume fixed; perfect mixing sets outlet concentration to the tank
concentration; constant temperature supports a fixed reaction rate. These are
assumptions, not solver guarantees.

Teacher reasoning / look for
Use the steady-concentration relation below: default gives 20/3, stronger reaction gives
10/3, zero reaction gives 10 g/L. Compare “Your Euler max error” with “Your half-step
max error”; some displayed baseline checks refer to prepared reference calculations, so
do not infer that every check validates learner code.
5 min 05. Separate two kinds of evidence
What would an analytic-solution match tell you? Propose one tracer observation that would
challenge the perfect-mixing assumption.
Teacher reasoning / look for
Agreement checks implementation of the stated equation. It does not test the real
tank’s mixing. A tracer experiment could compare concentration over locations or
outlet response with the well-mixed prediction.
5 min 06. Leave a short evidence record
Write one result, one check and one limitation. Answer the exit question and export the
original workshop’s Draft JSON or report; do not mark the full workshop complete.
Teacher reasoning / look for
Accept clearly labelled failed or unavailable runs. A precomputed reference is useful for
discussion but must remain labelled as reference, never the learner’s execution.

Exit question
Your numerical curve matches the analytic curve. Does that establish perfect mixing in a real
tank? What further evidence is needed?
Reference reasoning
No. It checks the chosen equation’s implementation. A physical observation, such as a
tracer experiment testing spatial concentration or outlet response, is needed to assess
mixing.
Misconceptions to discuss
A smooth or stable curve establishes a correct physical model.
A smaller time step repairs a missing reaction term.
A prepared reference figure is evidence that I ran my code.
These statements are misconceptions, not conclusions. Ask for the missing condition or evidence.
