# 第二批：閱讀路線、概念與長文工具

日期：2026-10-11。基準：已發布 `42a68fcb9e4eaa357a0e5a9661ed5add52fb007a`。

## 已實作範圍

- 兩條人工編排雙語路線：模型可信度、城市中的數學，各三篇主線與一篇進階選讀。時間由現有正文估算，保留每一步的先備要求及證據界線。
- 主題總覽及相關主題頁直接提供第一篇入口；文章末尾顯示所在路線與下一步。首頁專題捷徑連到模型可信度。
- 八個雙語概念，附簡釋、正文例子、常見誤解、適用範圍及原始來源。六篇試點文章的八個指定位置使用原生 details，無需 JavaScript 也可展開及到詞條頁。
- 概念與路線沿用搜尋類型、主題及分頁，支援另一語言的標題與別名；四項主導覽保持一致。
- 閱讀位置以共同文章 ID 和章節保存在獨立本機鍵值。35 組人工核對的章節對應；沒有對應時清楚提示，沒有按序號猜測。
- 續讀由讀者按鈕觸發；清除使用跨分頁世代標記，防止舊分頁把已清除位置寫回。既有稍後閱讀及教學紀錄格式不變。
- 文章 A4 列印保留標題、日期、讀前指南、正文、圖說、參考資料及正式網址；隱藏操作工具與延伸導覽，處理公式、表格及程式碼。

## 來源與結論界線

概念例子及路線說明均取自既有文章；科學正文、公式、圖件、圖說、日期及章節 ID 不改寫。實際十二份 Markdown 渲染比較確認，移除新增概念提示後，輸出與原文相同。穩健性例子限於符合假設的配對路由；CQR 保留交換性、邊際覆蓋及時序資料限制。合成、失敗及未通過絕對門檻的結果均明示。
