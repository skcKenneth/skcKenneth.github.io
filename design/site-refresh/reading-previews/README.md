# 第二批瀏覽器與列印預覽

本機正式建置預覽：`http://127.0.0.1:8767/`。這不是正式發布證明。

- `responsive-checks.json`：兩條路線、概念總覽、兩個詞條及交通長文，中英文各於 360、390、768、1280 px 和 100／200% 根字級共 96 組檢查，全部沒有文件橫向溢出。200% 是本機文字放大測試夾具，不等同所有瀏覽器縮放情況。
- `path-desktop.png`、`path-mobile.png`：模型可信度路線。
- `calibration-mobile.png`：概念詳情及來源導覽。
- `concept-mobile.png`、`concept-200.png`：使用鍵盤展開的原生概念解說；放大後仍無頁面橫向溢出。
- `print/`：實際產生的 A4 文件、逐頁文字／邊界檢查、選定頁面圖片及重建腳本。幾何檢查補充人工抽查，不代表所有分頁均經逐頁視覺審閱。

實際操作已檢查主題到首篇的一次點擊、路線下一步、概念 Enter 開關、搜尋英文別名返回中文詞條及語言切換保留條件。續讀由明確按鈕觸發，清除後重新整理不會復原位置。頁首焦點與章節映射問題已作為本批修正案例；最終重測結果記於 `../reading-batch.md`。
